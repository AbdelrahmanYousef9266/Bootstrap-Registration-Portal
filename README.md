# Bootstrap Registration Portal

A responsive Bootstrap 5 webpage that demonstrates Bootstrap forms, grid layout, tables, images, buttons, utility classes, and a responsive navbar.

---

## Features

- **Responsive Navbar** — Dark Bootstrap navbar with brand logo and hamburger menu on mobile
- **Hero Image Section** — Full-width responsive image with centered overlay text and call-to-action button
- **Registration Form** — Bootstrap card form with client-side validation
  - First Name and Last Name displayed side-by-side using Bootstrap grid (`col-md-6`) on medium and larger screens
  - Required Email and Password fields with validation feedback
  - Password show/hide toggle
  - Terms and Conditions checkbox
- **Responsive Table** — Striped and hoverable rows (`table-striped table-hover`) wrapped in `table-responsive`
- **Status Badges** — Color-coded Bootstrap badges (Active, Pending, Inactive) in the users table
- **Responsive Images** — Full-width hero image using `img-fluid`
- **Circular Image** — Profile avatar styled with `rounded-circle`
- **Bootstrap Utility Buttons** — Primary button visible on all screen sizes; Secondary button hidden on small screens using `d-none d-md-block`
- **Mobile-Friendly Layout** — Fully responsive across mobile, tablet, and desktop
